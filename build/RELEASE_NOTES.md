## MICO360 Doc Toolkit v7.6.2

**Pick your target size in KB or MB.**

**New features**
- Compress Image and Compress PDF: when you choose *Target file size*, the size now has a KB / MB picker — type "2 MB" or "250 KB". A size of 1 MB or more you used before reopens in MB.

**Bugs fixed**
- The compression log showed savings with a plus sign, such as "(+90%)", which read as if the file had grown. It now says "(90% smaller)" — or "larger" in the rare case a file grows.
- Adding files to the queue also wrote "No supported files found in the selection." in the Activity log, even though the files were added. That stray message is gone.

_Windows: the installer updates in place — your settings and favourites are kept. macOS: open the `.dmg` and drag the app to Applications._
